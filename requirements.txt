#    反过来升 transformers 又会让 mineru 公式识别报 cache_position 故障（见 环境说明.md 第 3 节）。
#    两头堵死，只有 1.3.5 能同时满足。FlagEmbedding 自己的依赖声明未约束 transformers，pip 装的时候不会报错。

# ⚠️ mcp 必须钉在 1.x，不要装 2.x（当前 PyPI 最新 2.3.0）
#    mcp 2.x 的 `mode="auto"` 会在 connect 时先发一个 2026 新协议方法 `server/discover`，
#    百炼 MCP 网关不认这个方法，回 HTTP 500；而 openai-agents 对「握手阶段的 5xx」
#    直接 raise_for_status()（非 MCPError），导致 negotiate_auto 里回退到 initialize 的
#    分支根本走不到 —— 报错：Failed to connect to MCP server 'xxx': HTTP error 500。
#    （404 时代反而能回退，所以表现为「开通服务后从 MCPError: Not Found 变成 500」）
#    1.x 走纯 initialize 握手，没有这个探测。装 1.x 只新增 httpx-sse，不动 transformers/torch。
#    另：openai-agents 的依赖是 mcp>=1.19.0,<3，1.30.0 满足。
